# QuadDesk 0.1.4 — горячие клавиши и включение зон

## Что обнаружено

На предоставленном скриншоте статус приложения — «Выключено». На последнем кадре целевой дисплей имеет размер 3840×2160, координаты (0, -2160), раскладка Quad рассчитана на четыре зоны 1920×1080. Это подтверждает расчёт зон, но не проверяет размещение окон.

Ранее любой отказ RegisterHotKey обозначался как «занята или зарезервирована Windows», без чтения кода ошибки. Точная причина каждого отказа на компьютере пользователя не установлена. Версия 0.1.4 показывает код ошибки и различает конфликт 1409 и другие ошибки.

QuadDesk управляет окнами внутри одного физического дисплея; в параметрах Windows новых дисплеев не создаёт. Постоянно разделять обои на отдельные рабочие столы приложение не должно. Границы видны при перетаскивании внутри выбранного дисплея или через «Показать зоны (5 сек)».

## Изменения

- Отдельное окно «Горячие клавиши» из главного окна и трея; оно же доступно во вкладке настроек.
- Русские названия действий, ввод текста, запись нажатием Ctrl/Alt/Shift с клавишей, очистка одной строки или всех сочетаний.
- «Базовый набор» без Win. Нажатия с Win при необходимости вводятся текстом.
- «Проверить» проверяет регистрацию в Windows и возвращает прежние назначения. Собственные горячие клавиши временно освобождаются, поэтому не создают ложных конфликтов.
- Повторные назначения и F12 выделяются; глобальные клавиши QuadDesk при записи временно отключены и восстанавливаются при отмене.
- Одно общее уведомление вместо отдельного всплывающего сообщения для каждого сочетания; подробности в таблице и журнале.
- Регистрации освобождаются и восстанавливаются при пересоздании скрытого окна обработчика.
- Явные кнопки «Включить зоны» / «Выключить зоны», зелёный активный статус, красный неактивный.
- Выбор дисплея теперь подтверждается кнопкой «Выбрать и включить зоны» и показывает границы на пять секунд.
- «Разместить окна по зонам» размещает подходящие открытые окна только на выбранном дисплее. Если окон больше зон, зоны используются повторно. Свёрнутые и исключённые окна не затрагиваются.
- Главное окно открывается при каждом запуске. DISPLAY-имя добавлено в список дисплеев для различения Generic PnP Monitor.
- Update-Portable.ps1 собирает и обновляет только EXE с резервной копией. config.json, layouts, workspaces, logs сохраняются. Версия существующей папки в её имени может оставаться 0.1.0; версия приложения в заголовке — 0.1.4.

## Базовые сочетания

| Сочетание | Действие |
|---|---|
| Ctrl+Alt+0 | Включить / выключить |
| Ctrl+Alt+1…9 | Активное окно на выбранном дисплее → зона |
| Ctrl+Alt+стрелки | Соседняя зона |
| Ctrl+Alt+M | Развернуть / восстановить в зоне |
| Ctrl+Alt+R | Восстановить размер |
| Ctrl+Alt+Shift+1/2/3/4/5/6 | Single / Dual Vertical / Triple Main / Quad / Main + 3 / Six |

Существующие сохранённые сочетания не меняются автоматически. После обновления выберите «Базовый набор», проверьте и сохраните. Другие программы могут занять любое сочетание; доступность проверяется на конкретном компьютере. Кнопки и автопривязка доступны без горячих клавиш.

## Обновление поверх исходников с исправлениями 0.1.1–0.1.3

1. Закройте QuadDesk через значок возле часов → «Выход». Крестик главного окна только скрывает окно.
2. Распакуйте ZIP обновления в D:\Users\Orkhan\Downloads\QuadDesk-v0.1.0 с заменой файлов.
3. Выполните в PowerShell:

```powershell
cd 'D:\Users\Orkhan\Downloads\QuadDesk-v0.1.0'
Unblock-File -LiteralPath .\Update-Portable.ps1, .\build.ps1, .\publish.ps1
.\Update-Portable.ps1 -TargetDirectory 'D:\Users\Orkhan\Apps\QuadDesk-v0.1.0'
```

TargetDirectory — существующая папка с запускаемым QuadDesk.exe. Если она отличается, укажите её фактический путь. Скрипт проверяет наличие EXE и прекращает работу, если приложение запущено. После успешной сборки запускает обновлённую программу. Старый EXE сохранён рядом как QuadDesk.exe.backup-дата.

Для отката: закрыть QuadDesk, скопировать сохранённую резервную копию поверх QuadDesk.exe. После возврата старой версии можно перенастроить клавиши через её настройки.

## Проверка после обновления

1. Заголовок содержит 0.1.4. Открыть «Горячие клавиши» → «Базовый набор» → «Проверить». Занятой строке назначить другое сочетание или очистить её. Нажать «Сохранить».
2. Выбрать телевизор по разрешению и расположению → «Выбрать и включить зоны»; статус должен быть «Активно».
3. Выбрать Quad 2×2 → «Показать зоны (5 сек)»: на телевизоре появляются четыре прямоугольника.
4. Перенести два обычных несвёрнутых окна на телевизор → «Разместить окна по зонам»: окна занимают разные зоны.
5. Активировать окно на телевизоре → Ctrl+Alt+1 и Ctrl+Alt+2. Затем проверить перетаскивание, начатое уже на телевизоре.
6. При неожиданном поведении нажать «Выключить зоны» или закрыть через трей. Прислать снимок главного окна и таблицы клавиш, а также logs/quad-desk.log из папки с EXE.

- .NET SDK 10.0.100, Linux x64.
- dotnet test: 81/81 PASS; 56 прежних и 25 новых случаев.
- dotnet build -c Release -r win-x64: PASS, 0 ошибок, 0 предупреждений.
- dotnet publish -r win-x64 --self-contained true с PublishSingleFile: PASS; получен единственный QuadDesk.exe.
- JSON раскладок / XML: 40 геометрических случаев PASS; 8 пресетов.
- CRC ZIP и список файлов: проверены при упаковке.
- WinForms UI, настоящая регистрация клавиш Windows, работа с Haier и выполнение PowerShell-обновления в Windows здесь не запускались. Проверки регистратора в модульных тестах используют подменный системный интерфейс. Сборка на компьютере пользователя повторит тесты с его SDK 10.0.401.
