# QuadDesk

[English](README.md) · [Русский](README.ru.md)

QuadDesk — утилита для Windows, которая превращает один физический дисплей в набор удобных рабочих зон.

Приложение **не создаёт виртуальные мониторы**, не ставит display-драйвер, не зеркалит экран, не захватывает видео и не использует OBS/VDD-подобную схему. Для Windows это всё ещё один монитор. QuadDesk управляет обычными окнами поверх этого монитора.

Основной сценарий: большой телевизор или ultrawide-дисплей должен вести себя как несколько чистых рабочих областей без путаницы от фейковых мониторов.

## Текущий статус

Стабильная публичная версия публикуется в **GitHub Releases**.

Разработка идёт в коротких ветках и pull request. Пока ветка не влита и не опубликована тегом релиза, её поведение считается тестовым.

## Что делает QuadDesk

- делит выбранный физический дисплей на настраиваемые зоны;
- не трогает основной монитор, если он явно не выбран;
- перемещает активное окно в выбранную зону;
- поддерживает собственные раскладки и редактирование границ зон;
- поддерживает горячие клавиши для раскладок, зон, перемещения и восстановления;
- даёт быстрые действия через трей;
- сохраняет и восстанавливает снимок рабочего пространства;
- проверяет стабильные GitHub Releases на наличие обновлений;
- собирает self-contained installer и portable ZIP через GitHub Actions.

## Чего QuadDesk намеренно не делает

- не ставит виртуальный display-драйвер;
- не создаёт фейковую multi-monitor топологию;
- не использует screen capture pipeline;
- не тащит браузерный runtime;
- не содержит телеметрии;
- не требует сети для обычного управления окнами.

## Раскладки

Встроенные раскладки:

| Раскладка | Описание |
|---|---|
| Single | Одна зона на весь выбранный дисплей |
| Dual Vertical | Две колонки |
| Dual Horizontal | Две строки |
| Triple Columns | Три колонки |
| Triple Main | Большая основная зона плюс две вспомогательные |
| Quad 2x2 | Четыре равные зоны |
| Main + 3 | Большая зона слева плюс три зоны справа |
| Six 3x2 | Три колонки на две строки |

Раскладки можно менять внутри приложения: делить зоны по горизонтали или вертикали, переименовывать, менять пропорции и сохранять отдельные варианты.

## Базовое использование

1. Установите QuadDesk или распакуйте portable-сборку.
2. Запустите `QuadDesk.exe`.
3. Выберите дисплей, которым должен управлять QuadDesk.
4. Выберите раскладку.
5. Перемещайте окна через меню в трее, горячие клавиши, автопривязку или кнопки главного окна.

QuadDesk управляет только выбранным дисплеем. Остальные мониторы остаются под обычным управлением Windows.

## Горячие клавиши по умолчанию

| Комбинация | Действие |
|---|---|
| `Ctrl+Alt+0` | Включить или выключить QuadDesk |
| `Ctrl+Alt+Shift+1` | Single |
| `Ctrl+Alt+Shift+2` | Dual Vertical |
| `Ctrl+Alt+Shift+3` | Triple Main |
| `Ctrl+Alt+Shift+4` | Quad 2x2 |
| `Ctrl+Alt+Shift+5` | Main + 3 |
| `Ctrl+Alt+Shift+6` | Six 3x2 |
| `Ctrl+Alt+1` ... `Ctrl+Alt+9` | Активное окно в зону 1 ... 9 |
| `Ctrl+Alt+стрелки` | Переместить активное окно в соседнюю зону |
| `Ctrl+Alt+M` | Развернуть или восстановить окно внутри текущей зоны |
| `Ctrl+Alt+R` | Восстановить предыдущий размер внутри зоны |

Комбинации можно менять в приложении. Если Windows или другое приложение уже заняло сочетание, QuadDesk покажет конфликт и позволит выбрать другое.

## Сборка из исходников

Требования:

- Windows x64;
- .NET SDK согласно `global.json`;
- Inno Setup 6 для сборки установщика.

Inno Setup ставится один раз:

```powershell
winget install --id JRSoftware.InnoSetup -e
```

Сборка, тесты и упаковка:

```powershell
pwsh -ExecutionPolicy Bypass -File .\publish.ps1
```

Артефакты появляются здесь:

```text
artifacts\release\
```

Release-builder создаёт:

- portable ZIP;
- Windows setup EXE;
- SHA-256 checksums.

## Релизный процесс

Версия хранится в `Directory.Build.props`.

GitHub Actions собирает и тестирует каждый push и pull request. Тег вида `vX.Y.Z` создаёт GitHub Release с установщиком, portable-архивом и контрольными суммами.

Политика веток:

```text
main = стабильный исходный код
feature/* или fix/* = разработка
vX.Y.Z tag = публичный релиз
```

## Обновления

Установленные сборки содержат пункт **Обновления…**.

Updater проверяет только стабильные GitHub Releases. Он не устанавливает pull-request artifacts, draft-релизы и preview-сборки.

Схема обновления:

1. QuadDesk находит последний stable-релиз.
2. QuadDesk скачивает setup EXE и `SHA256SUMS.txt`.
3. QuadDesk проверяет SHA-256 установщика.
4. QuadDesk копирует `QuadDesk.Updater.exe` во временную папку.
5. QuadDesk закрывается.
6. Временный updater запускает установщик и открывает обновлённый QuadDesk.

Updater вынесен в отдельный EXE, чтобы будущие релизы могли заменить и `QuadDesk.exe`, и `QuadDesk.Updater.exe` без ручного удаления/переустановки.

## Данные и логи

QuadDesk хранит локальные файлы рядом с исполняемым файлом:

```text
config.json
layouts\
workspaces\
logs\quad-desk.log
```

Заголовки окон, URL, буфер обмена и ввод с клавиатуры в логи не пишутся. Логи нужны только для диагностики приложения.

## Известные ограничения

- Окна, запущенные от администратора, могут не управляться из обычного процесса QuadDesk.
- Fullscreen-игры, borderless exclusive surfaces и защищённое медиасодержимое не являются надёжной целью для зон.
- Некоторые приложения сами ограничивают минимальный размер окна или используют нестандартные рамки.
- QuadDesk управляет обычными desktop-окнами; это не замена настоящему display-драйверу.
